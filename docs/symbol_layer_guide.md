# Symbol Layer Efficiency Guide (Layer 1)

The **Symbol Layer** (Sym+Num) is designed to make coding and data entry faster by placing common symbols and a number pad directly under your fingers.

**Activation:**
*   **Tap** `Sym Layer` key (Right Thumb, replacing Up Arrow) for **Sticky Mode** (one key press).
*   **Double-Tap** `Sym Layer` key for **Locking Mode** (remains active).

## 1. The "Mirrored" Symbol Cluster (Left Hand)
Instead of hunting for symbols on the number row or pinky corners, frequently used programming symbols are placed on the left hand home row and top row.

### Top Row (Left)
| Key | Symbol | Mnemonic/Usage |
| :--- | :--- | :--- |
| **Q (' )** | `]` (Right Bracket) | Closing array/list. |
| **P ( , )** | `}` (Right Brace) | Closing function/block. |
| **U ( . )** | `-` (Minus) | Subtraction, dash. |
| **Y ( P )** | `)` (Right Paren) | Closing argument list. |
| **; ( Y )** | `/` (Slash) | Division, comments. |

### Home Row (Left)
| Key | Symbol | Mnemonic/Usage |
| :--- | :--- | :--- |
| **A ( A )** | `[` (Left Bracket) | Opening array/list. |
| **O ( O )** | `{` (Left Brace) | Opening function/block. |
| **E ( E )** | `_` (Underscore) | Snake_case_variables. |
| **I ( U )** | `(` (Left Paren) | Opening argument list. |
| **G ( I )** | `\` (Backslash) | Escape characters. |

**Pro Tip:** Notice how pairing symbols are often adjacent or "mirrored"?
*   `[` `]` (Lower/Upper or Side-by-Side depending on layout variant)
*   `{` `}`
*   `(` `)`

## 2. The Integrated Numpad (Right Hand)
Your right hand becomes a full 10-key number pad. This is vastly superior to the horizontal number row for entering sequences of numbers.

*   **7 8 9**: Top Row (F, G, C positions on QWERTY / G, C, R on Dvorak)
*   **4 5 6**: Home Row (D, H, T positions)
*   **1 2 3**: Bottom Row (M, W, V positions)
*   **0**: Thumb (Space Key position)

### Math Operators
*   `+`: Pinky (Home Row)
*   `-`: Pinky (Top Row)
*   `*`: Pinky (Top Row Far)
*   `/`: Pinky (Top Row Far)
*   `=`: Top Row (Index)

## 3. Efficient Coding Workflows

### Typing "Snake Case" Variables
1.  Type word.
2.  Tap **Sym Layer** (One-Shot).
3.  Tap **E** (Left Middle Finger) for `_`.
4.  Type next word.
*   *Faster than holding Shift + Minus.*

### Typing Functions `myFunc()`
1.  Type `myFunc`.
2.  Tap **Sym Layer**.
3.  Tap **I** (Left Index) for `(`.
4.  Tap **Y** (Left Index Top) for `)`.

### Entering IP Addresses or Dates
1.  **Lock** Sym Layer (Double-Tap Thumb).
2.  Use Right Hand Numpad: `192`
3.  Use Left Hand `.` (Top Row) or Right Hand `.` (Bottom Row).
4.  Type `168`...

## Cheatsheet Summary

**Left Hand (Coding Symbols):**
*   **Brackets/Braces/Parens:** Main Cluster
*   **Underscore:** Home key (Middle Finger)
*   **Minus:** Top key (Index Finger)

**Right Hand (Data Entry):**
*   **Standard Numpad:** 7-8-9 / 4-5-6 / 1-2-3 layout
*   **Math Ops:** Pinky column
