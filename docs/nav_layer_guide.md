# Nav Layer Efficiency Guide

The **Nav Layer** is your "Command Center". It is designed to let you keep your hands on the home row while performing system shortcuts, navigation, and text manipulation.

**Activation:** Hold the **Left or Right Thumb (Command)** key.

## 1. The Power of "One Key" Shortcuts
Since the entire Nav layer automatically applies the `Command` (GUI) modifier to almost every key, you don't need to hold "Command + C" with two fingers. You just hold the Thumb and tap "C".

### General Workflow
| Action | Standard Way | **Nav Layer Way** | Efficiency Gain |
| :--- | :--- | :--- | :--- |
| **Copy** | `Cmd` + `C` | Hold Thumb + `C` | Less finger gymnastics. |
| **Paste** | `Cmd` + `V` | Hold Thumb + `V` | One-handed operation (if using Left thumb). |
| **Undo** | `Cmd` + `Z` | Hold Thumb + `U` (Top Row) | Dedicated Undo key. |
| **Redo** | `Cmd` + `Shift` + `Z` | Hold Thumb + `Y` (Top Row) | Dedicated Redo key. |
| **Select All** | `Cmd` + `A` | Hold Thumb + `A` | Instant selection. |

## 2. The Arrow Cluster (Right Hand)
This is the most critical feature. You never need to move your hand to the dedicated arrow keys again.

*   **Left (`←`):** Index Finger
*   **Down (`↓`):** Middle Finger
*   **Up (`↑`):** Ring Finger
*   **Right (`→`):** Pinky Finger

### Examples
*   **Browsing Code/Text:** Hold Thumb, use right hand to scroll through code.
*   **Selecting Text:** Hold **Thumb** + **Shift** (with left pinky) + **Arrow Keys** (right hand). This lets you select text without moving your wrists.
*   **Word Jumping:** Hold **Thumb** + **Option** + **Arrow Keys**. (Nav layer keys act as arrows, so adding Option makes them Option+Arrow).

## 3. Browser Navigation
Use the Nav layer to speed through web browsing.

| Action | Key Press (Holding Nav Thumb) |
| :--- | :--- |
| **New Tab** | `T` (Right Index) |
| **Close Tab** | `W` (Right Ring - Bottom) |
| **Reopen Closed Tab** | `Shift` + `T` |
| **Refresh Page** | `R` (Top Row) |
| **Find on Page** | `F` (Bottom Right) |
| **Focus URL Bar** | `L` (Home Row - Inner Index) |
| **DevTools** | `Cmd` + `Shift` + `I` (Bottom Row - Inner Index) |
| **Back / Forward** | `[` / `]` (Top Corners) |

## 4. Window Management
Manage your OS windows with the left hand while the right hand is on the mouse (or trackball).

| Action | Key Press (Holding Nav Thumb) |
| :--- | :--- |
| **Switch Apps** | `Tab` (Left Pinky) -> Cycles `Cmd+Tab` |
| **Close Window** | `W` (Right Ring) -> Sends `Cmd+W` |
| **Quit App** | `Q` (Left Ring - Top) -> Sends `Cmd+Q` |
| **Hide App** | `H` (Right Index - Home) -> Sends `Cmd+H` |
| **Spotlight Search** | `Space` (Right Thumb) -> Sends `Cmd+Space` |

## 5. Coding & IDE Workflows
*   **Comment Code:** Hold Thumb + `/` (if mapped to `Cmd+/`).
*   **Go to Line:** Hold Thumb + `L` (Cmd+L) works in many editors.
*   **Multi-Cursor:** In VS Code, holding **Option** + **Click** often adds cursors. Since you are already holding a "Command" layer, you can just click to add multi-cursors if you map `Cmd+Click`.

## 6. Pro Tip: The "Sticky" Nav
Your Nav layer (on the left thumb) is likely a "Smart Toggle".
*   **Hold:** Momentary access (release to stop).
*   **Tap:** Sticky access (press next key, then it releases).
    *   *Example:* Tap `Nav`, then tap `T`. Opens a new tab and immediately returns you to typing mode.
    *   *Example:* Tap `Nav`, then tap `Left Arrow`. Moves cursor once and returns to typing.
*   **Double Tap:** Locking Nav (stays on until you tap again).
    *   *Example:* Double tap `Nav`. Now you have a dedicated Arrow Key pad on your right hand for long scrolling sessions.

## Cheatsheet Summary

**Left Hand (Action Side):**
*   `Q`: Quit
*   `Z`: Undo (standard position) or `U` (custom Undo key)
*   `X`: Cut
*   `C`: Copy
*   `V`: Paste
*   `Tab`: App Switch

**Right Hand (Navigation Side):**
*   `H/T/N/S`: Left/Down/Up/Right Arrows
*   `L`: URL Bar / Go To
*   `F`: Find
*   `T`: New Tab
*   `W`: Close Tab/Window
